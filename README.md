## Free automation templates (khallihaai channel)

Ready-to-import n8n workflows, each explained step by step in a video on the channel.

| Template | What it does |
|---|---|
| [01 — PDF invoices to one Excel sheet](01-invoices-to-excel/) | Reads PDF invoices and pulls the invoice number, date and total into one Excel sheet |
| [02 — AI product descriptions](02-product-descriptions/) | Writes a marketing description for every product in an Excel sheet with a local AI model (Ollama) |
| [03 — Customer message triage](03-customer-messages/) | Sorts customer messages (order / complaint / question) into a labelled Excel sheet with local AI |
| [04 — PDF report summaries](04-pdf-summaries/) | Summarises long PDF reports into one page each (executive summary + key points + recommendations), locally |
| [05 — Certificates from an Excel list](05-certificates/) | Builds one personalised PDF certificate per name in an Excel sheet from a single HTML template, automatically (no AI) |
| [06 — Weekly file merge](06-weekly-merge/) | Merges several daily Excel files into one weekly workbook with two tabs: all merged rows + a summary of totals per day and per product (no AI) |
| [07 — Price list to catalogue PDF](07-catalog-pdf/) | Turns an Excel price list into one product-catalogue PDF: a cover, category sections and a price card per product, automatically (no AI; needs a browser/renderer to print the PDF) |
| [08 — Receipt photos to Excel (OCR)](08-receipts-ocr/) | Reads photos of paper receipts and pulls the date, total and shop into one Excel sheet with local OCR, flagging unclear rows for review |
| [09 — Auto-sort a downloads folder](09-file-organizer/) | Sorts a messy downloads folder automatically: invoices, contracts, photos and other into dated folders with clean names and an Excel log, by rule (type + a keyword in the PDF + the date), no AI |

Everything runs on your own machine. Sample files contain synthetic sample data only.
